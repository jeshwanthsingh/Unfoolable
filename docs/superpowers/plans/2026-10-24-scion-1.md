**Architecture:** Extend the existing protected shell, playbook store, coordinator and Proof pass; no new verdict authority or daemon.

**Spec:** ../specs/2026-10-24-scion-1-design.md

## Global constraints
- No push, merge, deployment or production restart. Preserve the dirty original checkout.
- Verdict core/archived core bytes unchanged; golden differences or negative-control PASS stop the round.
- Old seals verify with their recorded core/format; exact-item Touch ID and every-file review remain.
- Temp artifacts in .work; diagnostic processes retain ownership and cleanup checks.

## Review focus
- Hiding code in strings, docs, mixed hunks, unknown languages and parse errors: Task 1.
- Optional fields silently changing old approval hashes or lowering risk: Task 2.
- New findings confused with BASE findings; missing tools interpreted as clean: Task 4.
- Maintenance overlaps work, survives restart twice or overwrites live data: Task 5.
- Recheck attributed to the wrong Builder; format downgrade confuses old/new seals: Task 6.

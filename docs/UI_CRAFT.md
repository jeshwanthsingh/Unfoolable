# UI craft gallery

The current operational UI remains the default. These three alternatives are a choice exercise, not a replacement or a new authority surface.

Open Command Center normally with `./cc chat`, then on the same origin open:

- `/?craft=instrument` — A: graphite and brass, one precision Vault.
- `/?craft=glass` — B: a light layered decision sheet.
- `/?craft=night` — C: an original Three.js workshop diorama; no 3D import below 800px.

All read existing ticket/event APIs using the existing private operator capability. The gallery fetches at most 32 histories once, not a new live polling service. “Running now” filters captured current statuses and does not imply a live feed. Use the original UI for current running work and STOP ALL. Each route replays the selected ticket’s real sequence at one event per second, explicitly accelerated. Sidebar statuses are captured current metadata; hero statuses are historical. Full original requests remain available; headings are verbatim previews. No fake progress, generated work, new backend tables or decision endpoints.

Keep/Discard are deliberately disabled in history. Open live review returns to the unchanged exact-file/evidence/passkey flow. A historical pass cannot grant a current decision. Original approval, sandbox, Builder and protected-check behavior is unchanged.

Motion uses finite springs. Canvas renders on demand and disables rendering while hidden. Sound is off by default, opt-in, generated locally with Web Audio, and responds only to a newly observed passing lock; no downloaded audio. Reduced motion snaps directly. All original geometry/icons are authored for this exercise; no Apple, SF Symbols, Munder or copied scene assets.

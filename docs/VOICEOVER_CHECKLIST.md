# Observatory: manual VoiceOver check

Use real data without completing a decision. Automated axe cannot replace this check.

1. Start Unfoolable, turn on VoiceOver with Command–F5, and use Tab to reach Skip to work; activate it.
2. Read the header. Confirm Connected/Offline, Settings and Stop all have clear names. Do not activate Stop all.
3. Traverse the room buttons. Confirm each name and source explanation is read; Show/Hide room announces expanded state.
4. Open a task’s Proof. Confirm its title and result are read and focus stays visible.
5. Traverse the facts and seal. Confirm “unknown”, unchecked parts and broken/older seals are spoken honestly.
6. Choose Look at the changes, open each file, and verify the file names and changes are reachable with the keyboard. Do not accept.
7. Return to Proof and reach Accept. Confirm existing locked/unlocked behavior; stop before Touch ID.
8. Use a labelled isolated tripwire fixture. Confirm the sheet title, blocked action, task and time are read; Tab stays inside; Escape closes and returns focus.
9. Read the Night Shift briefing. Follow each named task to its Proof; an absent report must say no completed shift is recorded.
10. Enable reduced motion, test replay with arrow keys, and then test at phone width/200% zoom. Confirm no information requires sound, motion, hover or color alone.

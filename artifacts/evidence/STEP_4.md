# Lower-cost writer
Normal authoring now receives one fixed context pack: exact request, changed filenames (no Candidate contents), up to six relevant full BASE files, and the existing approved playbook test command when available. No read tools are exposed for this pack. Omitted files are explicit; the writer can return UNCLEAR or IMPOSSIBLE with empty code rather than guess.
The author, one BASE repair and one mutation-feedback retry share a 40,000 reported-token allowance. Unknown usage prevents another attempt; reported usage above remaining allowance stops the session and retains cost. Provider token notifications are not a prepaid hard quota: a notification can arrive after tokens were consumed. Any overshoot is retained, cannot qualify for promotion, and is not hidden as a 40k result.
Real disposable proof: 3,575 reported tokens; assertion-red BASE, two passing Candidate runs, 100% changed-line coverage and a killed mutant. No Candidate/Builder/hidden-grader inputs entered the author pack. Python subprocess coverage was separately proved at 100% using coverage.py's supported subprocess recording.
Promotion rule is frozen in code: complete old 11/8 and fresh 6/6 sets, >=60% confirmed in BOTH, zero false accepts in BOTH and measured mean cost <40,000. Unknown mean fails closed. Writer is still advisory until measured.
Tools are scoped to ignored .work/evidence/tools, not global or app runtime dependencies. Versions: coverage.py 7.16.2, diff-cover 10.6.0, mutmut 3.8.0, c8 12.0.0, StrykerJS 10.0.0. Builder model/runtime unchanged.
